# Spec Delta: interfaz-infantil

## Purpose
Garantizar una experiencia de usuario limpia, accesible y minimalista, con una paleta de colores suave y pastel pensada especialmente para la atención y confort visual de los niños.

## ADDED Requirements

### Requirement: Diseño Minimalista Infantil
El sistema SHALL implementar una interfaz con bordes redondeados, tipografía amable, contrastes accesibles y tonos pastel sin saturación excesiva.

#### Scenario: Navegación entre vistas
- **WHEN** el usuario navega entre el menú principal, los juegos y el panel de logros
- **THEN** las transiciones son fluidas, los botones tienen respuesta visual al tacto/clic y la mascota guía ofrece ánimos
